# PhotoVault

PhotoVault — настольное приложение для просмотра изображений из зашифрованного контейнера и консольная утилита для упаковки файлов. Контейнер защищён AES-256-GCM; ключ обрабатывается PBKDF2-HMAC-SHA256.

## Десктопное приложение

При запуске открывается нейтральный терминалоподобный экран с обновляющимися строками состояния. 30 шаблонов строк хранятся в `internal/ui/operations.json`; при сборке файл копируется в ресурсы macOS-приложения. Для перехода к интерфейсу введите значение переменной среды `LIBRARY_ACCESS_CODE` (регистр не важен). Вводимые символы не отображаются, пауза в 3 секунды между символами сбрасывает последовательность, а через 20 секунд без успешного ввода приложение закрывается. Если переменная не задана, вход недоступен. Коллекция отдельно открывается своим ключом. Вкладка **Создать** упаковывает файлы из выбранной папки в `photos.vault`; одинаковые файлы определяются по SHA-256 и повторно не добавляются. Флажок **Удалить исходные файлы после добавления** по умолчанию выключен; если включить его, файлы исходной папки удаляются после успешной записи коллекции. Вкладка **Восстановить** восстанавливает файлы в указанную папку; вкладка **Библиотека** показывает коллекцию и позволяет фильтровать её по категории и расширению, а также искать по имени и меткам. Поддерживаются визуальные файлы, видео, текст и документы; просмотр открывается во встроенных окнах. DOCX, ODT, PPTX, XLSX и EPUB показываются через встроенную панель Quick Look с исходным форматированием. PDF, RTF и DOC открываются в нативном просмотрщике; видео воспроизводится во встроенном плеере. Для видео и документов создаётся временная расшифрованная копия, удаляемая при закрытии окна просмотра.

Вкладка **Метки** управляет отдельными метками коллекции: их можно создавать, редактировать и удалять. У метки есть название, цвет и необязательное изображение; редактор открывается в модальном окне. В контекстном меню любого элемента выберите **Добавить метку…**, затем выберите метку для прикрепления. Метка хранится в зашифрованном каталоге коллекции как самостоятельная сущность и может прикрепляться к любым элементам. При переименовании связи сохраняются; удаление метки снимает её со всех элементов. Метки и связи доступны только после открытия коллекции с правильным ключом. Дважды щёлкните по превью, имени или меткам элемента, чтобы открыть его; листайте фото кнопками **Назад**/**Вперёд** или стрелками клавиатуры. Контекстное меню элемента также содержит действие **Удалить элемент**. В полноэкранном режиме есть кнопка удаления. Все операции доступны в окне приложения. Скрытые файлы и папки, чьи имена начинаются с точки (например, `.DS_Store`), не добавляются в коллекцию и скрываются при просмотре старых контейнеров; при следующем обновлении коллекции такие старые записи будут исключены.

Библиотека держит индекс и метаданные в памяти, читает содержимое контейнера блоками по 1 MiB и сохраняет миниатюры в LRU-кэше с лимитом 96 MiB. Два фоновых потока используют три приоритета: видимые миниатюры, ближайшие соседние и предположительные по направлению прокрутки. Для фонового декодирования ограничение — 24 мегапикселя на элемент. В полноэкранном режиме отдельный поток заранее загружает текущее фото и до двух соседей в каждую сторону; кэш полных изображений ограничен 192 MiB и удаляет элементы за пределами скользящего окна. Для полноразмерного декодирования установлен предел 24 мегапикселя. Это оставляет запас для кэшей и графических копий в рамках целевого бюджета 500 MiB. Пока открыто полноэкранное фото, фоновая загрузка миниатюр приостанавливается. Точный RSS также зависит от Go runtime, драйвера окна и графической памяти.

Существующие контейнеры PVLT0001 остаются поддержаны: при первом открытии с правильным ключом они переходят на потоковый PVLT0002, а исходный файл сохраняется рядом как `photos.vault.legacy` (при совпадении имени резервной копии добавляется номер). Миграция ограничена 128 MiB для старого файла и суммарного распакованного содержимого; при превышении исходник остаётся без изменений и приложение сообщает об ограничении. Консольный `Open` также оставлен как совместимый API, который собирает содержимое в память; для интерфейса используется потоковый `OpenSession`.

На macOS выполните `make build`. В `dist/Library.app` появится полноценный универсальный пакет приложения для Apple Silicon и Intel, с иконкой и метаданными macOS. Для сборки нужны Go, CGO и Xcode Command Line Tools. По умолчанию пакет подписывается ad hoc: разрешения macOS сохраняются для этой сборки, но после изменения бинарника могут запрашиваться снова. Чтобы сохранять разрешения и между пересборками, укажите постоянный сертификат подписи через `LIBRARY_CODESIGN_IDENTITY`.

Для интерактивного запуска дважды щёлкните `scripts/launch-library.command` в Finder. Он откроет Terminal; Unix-скрипт `scripts/launch-library.sh` также открывает Terminal, если запущен без TTY. Если `LIBRARY_ACCESS_CODE` уже задана, скрипт проверит старое значение. Чтобы изменить его, введите и подтвердите новое; оставьте поле нового значения пустым, чтобы запустить приложение с прежним кодом.

Просмотрщик декодирует JPEG, PNG, GIF, WebP, BMP и TIFF; неизвестное расширение проверяется по содержимому при показе миниатюры. Команды шифрования и расшифровки по-прежнему работают из терминала.

## Создание и расшифровка контейнера из терминала

```sh
photovault type=encrypt in="/path/to/files" out="/path/to/vault-dir" key="your secret key"
photovault type=decrypt in="/path/to/vault-dir/photos.vault" out="/path/to/restored" key="your secret key"
```

При повторном шифровании существующий контейнер в `out` объединяется с новыми файлами. Совпадающий относительный путь заменяется новой версией. Исходники остаются на месте.
Символические ссылки при упаковке пропускаются, чтобы не включать файлы за пределами выбранной папки; GUI показывает их количество.

Ключ задаётся в командной строке или в форме просмотрщика. Не передавайте его аргументом процесса в среде, где другие локальные пользователи могут читать аргументы процессов. Потерянный ключ восстановить нельзя.

## Структура кода

- `internal/vault` — формат контейнера, криптография, метаданные, создание и восстановление.
- `internal/catalog` — категории и расширения файлов.
- `internal/ui` — Fyne-экраны Library, Create и Restore.
- `internal/media` — запуск встроенного macOS-просмотрщика.
- `internal/cli` — разбор и выполнение консольных команд.
- `scripts` — сборка `.app` и native helper для Quick Look, PDF и видео.

UI и CLI используют один сервис `vault`; представление не содержит кода формата или шифрования.

## Версия приложения

Единственный источник версии — корневой файл `VERSION` в формате `MAJOR.MINOR.PATCH`. Исправления повышают PATCH, обратно совместимые функции — MINOR, несовместимые изменения — MAJOR. `make build` записывает значение в метаданные `.app` и встраивает его в CLI; `photovault --version` выводит встроенную версию. При подготовке следующего релиза обновляйте `VERSION` вместе с изменениями.
